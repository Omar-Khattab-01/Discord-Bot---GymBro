# GymBro Discord Bot

I built this Python Discord bot to keep track of my daily nutrition from the chat app I was already using. It records calories and macronutrients and lets me reuse saved meal information.

## What it does

- Record calories, fat, carbohydrates, and protein.
- Keep daily totals associated with a Discord user.
- Save named meals and retrieve their nutrition values.
- Add a saved meal to a day's intake.
- Store nutrition entries in local text records.

This is my earlier nutrition-tracking bot. My separate [GymBro Chatbot](https://github.com/Omar-Khattab-01/GymBroChatbot) explores a conversational fitness interface.
